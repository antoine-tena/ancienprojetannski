# 🎨 Guide utilisateur - Éditeur Visuel

## 🚀 Accès à l'éditeur

1. Connectez-vous avec un compte **administrateur** (superuser)
2. Visitez une page contenant des blocs éditables
3. Une **barre d'outils** apparaît en haut de la page

## 🎯 Activation du mode édition

Dans la barre d'outils en haut de la page :
- Cliquez sur le **toggle "Activer l'édition"**
- Le badge passe au vert : **Mode édition activé**

## ✏️ Éditer un bloc

1. **Survolez un bloc** avec votre souris
   - Une bordure bleue pointillée apparaît
   
2. **Cliquez sur le bloc**
   - 3 boutons apparaissent dans le coin :
     - 🟢 **Copier** : Duplique le bloc
     - 🔵 **Crayon** : Ouvre le panneau d'édition
     - 🔴 **Corbeille** : Supprime le bloc

3. **Cliquez sur le crayon bleu**
   - Un panneau latéral s'ouvre à droite
   
4. **Modifiez les champs**
   - Titre, texte, couleurs, etc.
   - **Les changements sont visibles en temps réel !**

5. **Fermez le panneau**
   - Cliquez sur "Fermer" ou en dehors du panneau

## 🎯 Réorganiser les blocs (Drag & Drop)

1. Activez le mode édition
2. Survolez un bloc
3. Cliquez sur la **poignée de déplacement** (icône ⋮⋮ en haut à gauche)
4. **Maintenez le clic** et déplacez le bloc
5. Relâchez à la position souhaitée

## ➕ Ajouter un nouveau bloc

1. Cliquez sur **"Ajouter un bloc"** dans la barre d'outils
2. Choisissez le type de bloc :
   - **Hero / Bannière** : Grande section avec titre et bouton
   - **Texte** : Paragraphe de texte simple
   - **Image** : Une image pleine largeur
   - **Call-to-Action** : Section colorée avec appel à l'action
   - **Carte** : Carte avec image, titre et description
3. Le bloc est ajouté en bas de la page
4. Éditez-le immédiatement

## 🗑️ Supprimer un bloc

**Méthode 1** : Bouton rapide
- Cliquez sur le bloc
- Cliquez sur l'icône **corbeille rouge**
- Confirmez la suppression

**Méthode 2** : Dans le panneau d'édition
- Ouvrez le panneau d'édition (crayon bleu)
- Cliquez sur **"Supprimer"** en bas à gauche
- Confirmez

## 📋 Dupliquer un bloc

- Cliquez sur le bloc
- Cliquez sur l'icône **copie verte**
- Le bloc est dupliqué juste en dessous

## 💾 Sauvegarder vos modifications

Cliquez sur **"Tout sauvegarder"** dans la barre d'outils.

## 🎨 Champs éditables

### Champs communs à tous les blocs
- **Titre** : Le titre principal du bloc
- **Contenu** : Le texte descriptif

### Blocs Hero et CTA
- **Couleur de fond** : Couleur d'arrière-plan
- **Couleur du texte** : Couleur du texte
- **Texte du bouton** : Label du bouton d'action
- **URL du bouton** : Lien de destination

### Blocs Image
- **URL de l'image** : Lien vers l'image à afficher
- **Texte alternatif** : Description pour l'accessibilité

### Blocs Texte
- **Alignement** : Gauche, Centre, Droite

## ⚡ Astuces

### Édition rapide
Les changements sont **visibles en temps réel** pendant que vous tapez !

### Raccourcis
- **Échap** : Ferme le panneau d'édition
- **Clic en dehors** : Désélectionne le bloc

### Ordre des blocs
L'ordre visuel correspond à l'ordre de création. Utilisez le drag & drop pour réorganiser.

### Aperçu
Pour voir le rendu final, **désactivez le mode édition** avec le toggle en haut.

## ⚠️ Bonnes pratiques

1. **Sauvegardez régulièrement** vos modifications
2. **Testez les liens** des boutons avant de publier
3. **Vérifiez les couleurs** : contraste texte/fond
4. **Prévisualisez** en désactivant le mode édition
5. **Utilisez des images optimisées** (pas trop lourdes)

## 🆘 Problèmes courants

### Le mode édition ne s'active pas
- Vérifiez que vous êtes connecté en tant qu'**administrateur**
- Rechargez la page (F5)

### Les changements ne se sauvegardent pas
- Cliquez sur "Tout sauvegarder"
- Vérifiez votre connexion internet

### Un bloc ne se déplace pas
- Assurez-vous de **cliquer sur la poignée** (⋮⋮) et non sur le bloc lui-même

### Le panneau d'édition ne s'ouvre pas
- Désactivez puis réactivez le mode édition
- Rechargez la page
